# ソナー探知 回避 潜水艦アクションゲーム

円形ソナー画面を模したUIで潜水艦を操作し、機雷・海底山脈を避けながら敵艦に魚雷を当てるアクションゲーム。

## 特徴

- 回転スキャンライン付きの本物らしいソナーUI（緑/黒テーマ）
- 深度（浅/中/深）・速度（遅/速）・ステルスモードの3次元コントロール
- 敵はステルスOFF時や高速移動で検知しやすくなるリアルな音響学習要素
- キーボード（WASD/矢印）とタッチ操作両対応
- 魚雷・機雷・海底山脈・敵艦のパーティクルエフェクト付き爆発演出

## 技術

- Pure Canvas 2D + requestAnimationFrame ゲームループ
- 敵AIは検知タイマーによる追跡モード切替
- PointerEvents APIでタッチ/マウス統合
